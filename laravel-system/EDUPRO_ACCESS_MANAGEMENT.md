# EduPro Access Management

EduPro now includes custom role records, permission groups, permission-role grants, legacy-role compatibility, branch-scoped account provisioning, account activation/suspension, secure password reset, session revocation, login history data, and account audit logging.

The user management page is `/portal/users` and requires the `users.manage` permission. Super Admin is protected against reassignment/removal by non-Super-Admin accounts. Public registration remains restricted to Student and Guardian accounts.
